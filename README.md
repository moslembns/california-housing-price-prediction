# California Housing Price Prediction
## Project Overview
This project uses Machine Learning to predict median house values in California districts based on information about housing, population, and location.
The goal is to explore a real-world dataset, prepare the data, train different regression models, and evaluate their predictive performance.

## Project Objectives

- Explore and understand the dataset.
- Identify and handle missing values.
- Create useful features through feature engineering.
- Prepare numerical and categorical data.
- Build Machine Learning pipelines.
- Train and compare regression models.
- Evaluate model performance using Root Mean Squared Error (RMSE).
- Use Grid Search Cross-Validation to find better model hyperparameters.

## Technologies and Libraries

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. **Data Exploration:** Understand the dataset, examine distributions, and explore relationships between variables.
2. **Data Preparation:** Handle missing values and prepare numerical and categorical features.
3. **Feature Engineering:** Create additional features to improve the information available to the models.
4. **Data Transformation:** Build pipelines using imputation, encoding, and feature scaling.
5. **Model Training:** Train regression models, including Linear Regression and Decision Tree Regression.
6. **Model Evaluation:** Evaluate predictions using RMSE and investigate model performance.
7. **Hyperparameter Tuning:** Apply GridSearchCV to search for better model configurations.
8. **Final Evaluation:** Evaluate the selected model on the test dataset.
